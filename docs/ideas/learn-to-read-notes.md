# Idea: learn to read sheet music

**Status:** idea, not scheduled. Raised by the owner on 2026-10-23.

The owner plays by ear and does not read notes; piano-steps deliberately removes the need to. A
separate (or companion) mode could teach reading gradually, using the same lesson data:

- **Flashcards on the staff** — a note appears on the treble/bass staff, the user taps the key.
  Spaced repetition per note; start with C4–G4, grow outward.
- **Bridge from what they already know** — the `sheet` variant shows notation in sync with the
  keyboard for songs the user is learning anyway, so the staff becomes familiar "for free".
- **Rhythm reading** — show durations as note shapes against the tempo grid of a lesson.
- **Key signatures** — why the song "has all those #": tie sharps to the black keys used.

Open questions: separate app vs a mode in piano-steps; whether to reuse lessons as exercises
(likely yes — practising reading on a melody you want to play is the motivation).
